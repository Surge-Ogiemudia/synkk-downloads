# PharmaStackX Terminal: downloads

Release channel for **PharmaStackX Terminal** (Synkk), the Windows desktop app that connects a pharmacy's existing point-of-sale or inventory software to [PharmaStackX](https://psx.ng), so its medicines become searchable by patients nearby.

## Download

Get the latest installer from **[Releases](https://github.com/Surge-Ogiemudia/synkk-downloads/releases/latest)**.

Installed copies update themselves automatically from this channel.

## Requirements

- Windows 10 or later (64-bit)
- A PharmaStackX pharmacy account

The app's source code is private. This repository only hosts the published installers.
